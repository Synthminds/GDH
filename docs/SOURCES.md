# Sources

These sources informed GDH. Each row gives the title, the publisher or author, and how the source was used. GDH copies no sentence and no code from any of them. Rules are restated in the kit's own words, and each skill names its sources in a short list.

Reading depth differs. "Read" means the source text was read during the research on 2026-11-23. "Search" means a search summary named the source and the page was not opened. "Memory" means the rule is stated from prior knowledge of the source. A rule from a "Search" or "Memory" source is a default in the kit, never a gate.

## Asset sources

`kit/catalogs/assets.json` lists 174 free asset sources. For 108 of them the license page was read on 2026-11-23. For 66 it was not, and `verifiedOn` is `null`. The catalog records each license in the source's own words in short form; `find-assets` reads the license page again before any use.

## The coding harness

GDH follows the shape of the GCH kit: a registry, a kernel, moments, a check engine with one code for each rule, and an export with a managed block. GDH copies no GCH code and no GCH prose. It names GCH skills only as options when GCH is installed.

## What was not used

- No text of any book or guide is quoted in the kit beyond a few words.
- No third-party skill is vendored. Wired skills are named with their install lines in `kit/kit.json`.
- No font, icon, image, model or component from any source ships in this repository.
