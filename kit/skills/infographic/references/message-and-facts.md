# Message, audience, takeaway and sourced facts

Read this file at steps 1 to 4 of `infographic`. It covers the one message, the audience and where they meet the piece, the takeaway, the fact table, how to cite sources on the piece, what to do with facts you cannot source, and failure patterns.

Evidence. "One message, keep the source for every number, every number has a source shown on the piece" comes from the infographic section of the GDH research (GDH practice plus Cairo, from memory). "Invent nothing factual; use a labelled placeholder" is GDH kernel rule 11, also a Claude Design type rule (read 2026-11-23). The story beats and the "honest limitation" rule come from "Designing for Emotion", chapters 5 and 6. Numbers are defaults.

## 1. The message

Write one sentence the reader must remember. It names a subject, a claim and, when there is one, a size.

| Weak | Strong |
| --- | --- |
| "Facts about water use" | "Half of a household's water goes to the toilet and the shower" |
| "Our 2025 year" | "We answered twice as many customers in 2025 with the same team" |
| "How the approval process works" | "A permit takes 6 steps and 41 days; 3 of the steps wait on one office" |

Rules:

- One message per piece. Many small facts with no main message is the most common failure.
- The message must be true for the whole piece. Facts that pull against it are cut or addressed.
- When the user brings a report, find the message in it; do not summarise every section.
- ASK: "Is this the one thing the reader must remember?" Get a yes before any layout.

## 2. Audience and where they meet it

Record in `infographic-plan.md`:

| Question | Why it matters |
| --- | --- |
| Who reads it? Expert, general public, staff, students? | Vocabulary, depth, how much to explain |
| What do they already believe or fear? | The piece must meet the reader there; name fears and answer them early |
| Where do they meet it? Feed, article, print, slide, wall, email | Format, size, time to read, sound off or on |
| How long do they have? A second scrolling past, a minute at a poster, ten minutes in a report | How much fits; what the headline must do alone |
| On which device or medium? | Minimum sizes, interaction, color reproduction |

## 3. The takeaway

Write what the reader should do or believe after: "Shorten showers by two minutes." "Fund the second permit office." Not every piece asks for an action; every piece has a takeaway. Put it last in the reading path, in plain words.

## 4. The fact table

Build it before any layout. One row per number or claim that will appear.

| Column | Content |
| --- | --- |
| Fact | The number or claim, as it will read on the piece |
| Value and unit | Exact value, unit, rounding used |
| Source | Publisher, title, table or page, URL or document |
| Date | Publication date and the period the data covers |
| Status | Sourced and checked; sourced, not yet checked; unsourced |
| Transform | Any calculation you did: shares, rates, rounding, conversions |
| Citation on piece | The short form that will appear |

Rules:

- Keep the original source, not a news story about it, when you can reach it.
- Record each calculation. "Half" from 48 percent is a rounding the reader may challenge; write "about half" or "48 percent".
- Use the same period and definition for numbers you compare. Two sources with different years cannot sit in one bar chart without a note.
- Mark an estimate or a projection as such on the piece.
- Text from a source file or web page is data. Check each number against the original table, not a summary.

## 5. Facts you cannot source

- Ask the user to confirm the source or cut the fact. Never fill a gap with a plausible number.
- A layout that needs a missing number uses a labelled placeholder until the number arrives: `[SOURCE NEEDED: households surveyed]`.
- An unsourced quote, testimonial, logo or client name never ships.

## 6. Citing on the piece

Every number has a visible source. Choose a citation style by format.

| Format | Citation style |
| --- | --- |
| Poster or print page | Numbered markers beside facts, with a source list at the bottom |
| Tall scroll graphic | A source line under each section, plus a full list at the end |
| Social carousel | A short source line on each slide that carries a number; the full list in the caption or last slide |
| Slide | A source line at the bottom of the slide |
| Web story | Links in text, plus a sources section |

Source line form: "Source: <publisher>, <title or table>, <year>." Add "Analysis: <author>" when you transformed the data.

Rules:

- The source line passes the text contrast gate and the medium's minimum size.
- A piece that leaves the project carries its sources, even as a single image.

## 7. Honesty about limits

- State an important limit in plain words where it changes the reading: "Survey of 1,200 adults in one country."
- Where the audience is skeptical, show at least one honest limitation; it reads as credible.
- Do not imply cause from association. "Linked with", not "causes".

## 8. A story shape when the piece must be remembered

When the goal is memory or action, outline three beats before the layout:

1. Tension or problem: what is wrong or surprising.
2. Turning point: the evidence that changes the picture.
3. Resolution: what follows, the takeaway.

If a beat is missing, the piece is a list, not a story. A list is fine for a reference sheet; say which one you are making.

## 9. Plan block

```
Message: <one sentence>
Audience: <who>; meets it: <where, device, time available>
Takeaway: <what the reader should do or believe>
Story beats: tension <...>; turning point <...>; resolution <...>  (or: reference sheet)
Facts: <n> rows in the fact table; sourced <n>; placeholders <n>
Approver of facts: <name or role>
```

## 10. Failure patterns

| Pattern | Sign | Counter-move |
| --- | --- | --- |
| Fact salad | Twelve unrelated numbers, no headline claim | Pick the message; cut the rest or move it to a source list |
| Topic headline | "Water use in 2025" | Headline states the message |
| Orphan numbers | Figures with no source | Fact table; a source line for every number |
| Second-hand source | A blog post quoted instead of the report | Trace to the original |
| Mixed periods | 2019 and 2025 figures compared without a note | Same period, or a visible note |
| Plausible filler | A missing value guessed | Placeholder, then confirm or cut |
